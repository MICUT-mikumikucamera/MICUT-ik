# 성윤님 전달용 모델·좌표 기준

현재 제안하는 첫 연결 기준이며, 민재님 최종 확인 전 테스트 설정임.

## 1. 모델·렌더 환경

- 테스트 외형: 제공받은 `legend_pretty_miku_look.blend`
- 실행 환경: Blender 5.2.0 LTS / Cycles CPU
- 제공 VRM에는 미쿠 외형 대신 Cube 메시가 있어 이번 렌더에 사용하지 않음
- 원본 모델 파일은 별도 전달. 저장소에는 원본을 넣지 않음

## 2. 크기·배율

기본 서기 프리셋 적용 후 source mesh의 발바닥에서 외형 최상단까지 높이는 약 **1.54937058 Blender 단위**임. 렌더 어댑터에서 목표 키 **1.58m**로 맞추기 위해 균일 배율 **1.01976894**를 적용함.

1.58m는 연결 확인용 설정이며 최종 캐릭터 키 확정값이 아님.

정규화한 외형 크기:

| 항목 | 값 |
|---|---|
| 가로 | 약 0.64521744m |
| 높이 | 1.58000000m |
| 앞뒤 | 약 0.51944977m |

머리카락·의상·손을 포함한 전체 외형 경계이며, 몸체 충돌 박스는 아님. 정확한 비대칭 경계는 `model_manifest.json`의 `normalized_local_bounds_m.min/max` 사용. 단순히 가로/2·앞뒤/2로 대칭 처리하지 않음. 방향 적용 후 월드 경계도 별도 제공함.

## 3. 위치 기준점

입력의 `feet_center_on_ground` 사용 가능. 양발 그룹에 속한 메시의 발바닥 근처 정점에서 좌우 바닥점을 추출하고 그 사이를 기준점으로 삼음. 모델 원점과의 오프셋은 렌더 어댑터에서 보정함.

`anchor_position`의 Y=0에 맞추며, 양발 높이 차이도 보고함. 이번 모델에서는 오차가 0.001mm 미만임. 다른 모델에서 발바닥이 비대칭이면 바닥에 낮은 발을 맞추고 경고하며, 발 IK로 자동 수정하지 않음.

이 단계에서는 바닥에 선 경우만 지원. 의자 위·계단 등 Y가 0이 아닌 지지면은 입력 오류로 반환함.

## 4. 기하 월드 좌표

미터, X 오른쪽, Y 위, Z 전방, 카메라 아래 바닥 원점으로 전달하면 됨. Blender의 Z-up 변환은 어댑터에서 처리함.

`spatial_info.json`은 배치에 사용한 사진·좌표 변환과 동일한 파일을 전달해야 함. 카메라 위치는 `cam_to_world.t`이며 바닥 원점과 다름. K의 fx/fy/cx/cy가 필요하며, 누락 시 임의 값으로 진행하지 않음.

## 5. 방향·포즈

- `action`: `stand`
- `pose_id`: `stand_default`
- `facing_rule`: `look_at_camera` 사용 가능, 수평 회전만 적용
- 이후 명시 방향은 `world_direction` + `facing_direction: [x, 0, z]` 사용 가능
- yaw 각도 단독 입력은 아직 지원하지 않음

`stand_default`는 제공 모델의 팔을 내린 고정 프리셋. 새 모델로 바꾸면 포즈·발바닥·크기 재검증 필요.

## 6. 함께 주고받을 자료

렌더 쪽에서 `model_manifest.json`을 먼저 공유하고 배치 파트가 동일한 모델·배율·포즈를 사용. 배치 쪽에서는 placement JSON과 그 사진의 spatial_info.json 전달. 화면 잘림은 보고서로 반환하며 임의 축소·위치 변경은 하지 않음.
